# 路口拥抱 · 视频生成项目

一个由 Seedance 2.5 生成的青春剧情 / 荒诞喜剧短片。黄昏的城市十字路口，韩系少女与长相酷似猪八戒的腼腆少年在人行道上相拥，却被开车前来的父亲打断，少年慌张跑开。

## 生成参数

- 模型：Seedance 2.5（seedance_2.5）
- 时长：30 秒
- 比例：16:9
- 分辨率：1280 × 720
- 条数：1 条连续成片
- 类型：纯文本生成（text-to-video）

## 文件结构

- `storyboard.md`：完整分镜脚本（时间、运镜、画面、声音）
- `prompt.md`：视频生成提示词，可直接复用与迭代

## 角色设定

- **女孩**：18 岁韩系清新少女，长发淡妆，米色针织开衫搭配浅色裙装，气质温柔。
- **男孩**：18 岁人类少年，长相酷似猪八戒——圆胖脸、上翘的圆鼻头与显眼鼻孔、招风大耳、厚唇小眼，憨厚喜感；现实高中生装扮，性格腼腆善良。
